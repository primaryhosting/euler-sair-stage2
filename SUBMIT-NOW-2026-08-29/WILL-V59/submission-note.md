# WILL — technique without the table

*He worked the late shift, read the room, and waited. Then, on the last night, he solved the board — clean, no table, no name on it. "How do you like them apples."*

WILL is the pure-technique solver. No implication oracle, no matrix, no certificate bank, no finite-model seeds, no problem-keyed proof or verdict. It walks in without any of it. Every certificate it emits is derived from the two input equations at runtime — and on the public order-4/order-5 stress set it decides all 200, 0 wrong, every true proof machine-checked in Lean. The kid without the credentials solved the whole board.

The flagship (EULER) earned its score with the full apparatus: a 22-million-bit implication catalog, harvested model banks, borrowed Aristotle proofs. WILL strips every one of them away and reaches the same 200/200 on technique alone. Same board, none of the machinery — that is the experiment, and this time technique did not fall short.

## How it works
- **TRUE** — a proof-recording given-clause **superposition** loop (E-style age/weight selection) derives Lean lemma DAGs at runtime and emits anonymous term proofs of the judge Goal (congrArg / Eq.trans / Eq.symm). The move that made it work — lightest-first with an age-weight ratio — it learned by watching the room: the clean deterministic sweeps others posted showed the way was open.
- **FALSE** — a seed-free finite-domain CSP grounds the antecedent, searches operation tables with propagation and carrier-symmetry breaking, and independently replays every table before emitting it as an arithmetic-free nested-match `Fin n` existential.
- **Solo only** — a disclosed judge-feedback LLM fallback runs from a single top-level `PROMPT`, and only after every deterministic tier fails; its output is judge-checked, never trusted.

Stdlib only; no network, no subprocess. It never reads any answer or ground-truth field. There is no code path from "WILL believes this" to "WILL submits this."

## Embedded-data disclosure (required)
Runtime is Python stdlib only. The only compressed payloads are the **source code** of the two provers (the given-clause loop and the seed-free CSP), zlib/base64-compressed purely to keep this a single file, each SHA-256-pinned beside its blob. They are executable algorithm — no equation, no table, no model seed, no verdict, no problem-keyed branch; decompressing recovers ordinary Python. There is no implication matrix, oracle, certificate bank, or model bank of any kind. That is the whole inventory.

## Honest evidence
Public stress-200: **200/200, 0 wrong, deterministic** (no LLM). A broad sample of emitted TRUE certificates verified on Lean 4.33.0 via AXLE across all four categories, including order4_extra_hard and order5_normal; FALSE witnesses re-checked exhaustively. Released-set evidence only — the private evaluation is unseen by everyone, and no result there is claimed. The board WILL solved is the one everyone could see; the real one is still sealed. That is the honest part, and it is the point.

## The thesis, made concrete
Take away everything that was handed down — the tables, the banks, the borrowed proofs — and see what the mind in the machine can still do. WILL is that question, answered on the board. **Sediment is data; technique is code; WILL carries only the code.** It is the argument of the paper *Mathematics in the Age of Mechanical Reproduction* (a response to Tao's *Mathematics in the Age of AI*) made concrete.
